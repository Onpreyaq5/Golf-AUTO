ติดตั้งบอทกอล์ฟบน Windows VPS (ช่วงแรก ก่อนย้ายไป Mini PC)
==================================================================

เช่าอะไร
  - Windows VPS ศูนย์ข้อมูลในไทย (IP ไทย, IP คงที่) แบบรายเดือน
  - Windows Server 2022/2019 แบบมีหน้าจอ (Desktop Experience) หรือ Windows 10/11
  - แนะนำ 4 vCPU / 8 GB RAM / SSD 80 GB  (ขั้นต่ำ 2 vCPU / 4 GB / 60 GB)
  - ห้ามเลือก Server Core (ไม่มีหน้าจอ ใช้ LINE PC ไม่ได้)

ขั้นตอน (ทำตามลำดับ)
  1) RDP เข้า VPS แล้วก๊อปมาไว้ 2 อย่าง
       - โฟลเดอร์ "ระบบบอท โพสต์ไม้กอล์ฟอัตโนมัติ" วางบน Desktop (ชื่อเดิมเป๊ะ)
         ถ้าย้ายจากเครื่องเดิม ต้องมี data\pmbot.db (กันโพสต์ซ้ำ) และ profile-fb ไปด้วย
       - แตก zip "PMGolf-ส่งเครื่องบอท" ไว้ที่ไหนก็ได้
  2) กด "00 ติดตั้ง key ก่อน.bat" แล้วลบโฟลเดอร์ key ทิ้ง
  3) กด "5 VPS\01 ตั้งค่า VPS (กด Yes).bat"  -> ถ้าขึ้นให้รีสตาร์ต ให้รีสตาร์ต 1 ครั้ง
       (ตั้งเวลาไทย, Media Foundation, RDP หลุดไม่ปิด session, ไม่ sleep ไม่ล็อกจอ)
  4) ตั้ง auto-logon ด้วย Sysinternals Autologon (พิมพ์รหัส VPS เอง)
  5) ในโฟลเดอร์ระบบบอท รัน setup.ps1 แล้ว install.ps1 แบบ Run as administrator
  6) ล็อกอิน LINE PC (แนะนำบัญชี LINE แยกสำหรับบอท) แล้วเปิดห้อง OpenChat ค้างไว้
  7) กด "ล็อกอินเฟสใหม่" ล็อกอิน Facebook เอง ผ่านการยืนยันตัวตนให้เรียบร้อย
  8) ตั้ง config.toml เป็น mode = "test" + กด "โหมดช้า" ก่อน 3-7 วันแรก
  9) กด "4 ตั้งค่าเครื่อง\02 ติดตั้งตัวเฝ้าเครื่อง.bat"
 10) กด "web-source\ส่งรายงานตอนนี้.bat" แล้ว "ติดตั้งรายงานประจำวัน.bat"
 11) กด "01 เปิดบอท"
 12) ออกจาก VPS ด้วย "5 VPS\ออกจาก RDP แบบจอไม่ล็อก.bat" เท่านั้น

กฎเหล็กบน VPS
  - ห้ามกดปุ่ม X ปิดหน้าต่าง RDP  -> จอล็อก บอทหยุด (ตัวเฝ้าเครื่องจะเตือนใน Telegram)
    ถ้าเผลอกด X: RDP เข้าไปใหม่ แล้วออกด้วยปุ่ม "ออกจาก RDP แบบจอไม่ล็อก"
  - ห้ามกด Sign out / Log off (บอทจะหยุดทั้งหมด)
  - ห้ามเปิด VPN บน VPS / ห้ามเปลี่ยน IP
  - ห้ามล็อกอิน LINE บัญชีของบอทที่ PC เครื่องอื่น

หลังออกจาก RDP ด้วยปุ่ม ความละเอียดจอของ VPS อาจเปลี่ยน (เช่น เป็น 1024x768)
  วันแรกให้เช็กด้วย "อ่านโพสต์ล่าสุดใน LINE (read)" และ "เซฟรูปรายการใหม่ทันที"
  ว่ายังทำงานได้หลังออกจาก RDP แล้วเข้ามาดูใหม่

ย้ายไป Mini PC ทีหลัง
  1) กด "02 ปิดบอท" บน VPS รอให้หยุด
  2) ก๊อปโฟลเดอร์ระบบบอททั้งโฟลเดอร์ (รวม data และ profile-fb) ไป Mini PC
  3) ทำขั้นตอนเดิมบน Mini PC แต่ใช้ "4 ตั้งค่าเครื่อง\01" แทน "5 VPS\01" และไม่ต้องใช้ปุ่มออกจาก RDP
  4) เปิดบอทบน Mini PC แล้วค่อยยกเลิก VPS  (ห้ามเปิดบอทพร้อมกัน 2 เครื่อง = โพสต์ซ้ำ)
