ติดตั้งรายงานประจำวัน + ตัวดึงเว็บ บนเครื่องบอท
==================================================

ต้องก๊อปไปที่เครื่องบอท 2 อย่าง
  1) โฟลเดอร์ web-source ทั้งโฟลเดอร์ (วางที่ไหนก็ได้ เช่น Desktop)
  2) ไฟล์ token: %USERPROFILE%\.pmgolf\telegram.json
     วางไว้ที่ C:\Users\<ชื่อผู้ใช้บนเครื่องบอท>\.pmgolf\telegram.json
     ห้ามใส่ไฟล์นี้ใน git หรือส่งในแชท

ขั้นตอน
  1) ดับเบิลคลิก "ส่งรายงานตอนนี้.bat"  -> ต้องได้รายงานในกลุ่ม PMGolfAdmin
     ครั้งแรกถ้ายังไม่มีจุดเริ่มฝั่งเว็บ ให้เปิด cmd ในโฟลเดอร์นี้แล้วพิมพ์
       python daily_report.py --dry-run --web-since <เลขสินค้าล่าสุดที่โพสต์แล้ว>
  2) ดับเบิลคลิก "ติดตั้งรายงานประจำวัน.bat" -> ส่งเองทุกวัน 21:30
     (ใช้ Python ของบอทเองอัตโนมัติ)
  3) (แนะนำ) ติดตั้งตัวเฝ้าเครื่อง: บอทกอล์ฟ\4 ตั้งค่าเครื่อง\01 และ 02

ถ้ารายงานบอกว่า "อ่านโพสต์ LINE จากฐานข้อมูลบอทไม่ได้"
  ชื่อคอลัมน์ใน pmbot.db ไม่ตรงกับที่เดาไว้ ส่งชื่อตาราง/คอลัมน์ให้ผู้ดูแลปรับ crosscheck.py

ถอนงาน: powershell -ExecutionPolicy Bypass -File install-daily-report.ps1 -Uninstall
เปลี่ยนเวลา: powershell -ExecutionPolicy Bypass -File install-daily-report.ps1 -At 22:45
